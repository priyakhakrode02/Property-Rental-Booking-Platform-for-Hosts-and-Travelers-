# Property Rental Booking Platform for Hosts & Travelers

A web application that allows travelers to explore properties, search for suitable accommodations, book properties, and write reviews.
Admins can manage property information and perform CRUD operations.

## Features
- User login and logout.
- Search and view properties.
- Book properties.
- Write reviews for properties.
- Admin can add, edit, view, and delete properties.

## Tech Stack
- *Frontend:* HTML, CSS
- *Backend:* JavaScript, Node.js, Express.js
- *Database:* MongoDB
